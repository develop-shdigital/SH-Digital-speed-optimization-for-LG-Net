# Claude Code in this repository

## Ponytail is on

For every coding task here, work in Ponytail mode (lazy senior dev mode, level full): load the
`ponytail` skill (`.claude/skills/ponytail/SKILL.md`) and follow it. "stop ponytail" or "normal
mode" turns it off for the session; `/ponytail lite`, `/ponytail full` or `/ponytail ultra`
switch the level. The other skills: `/ponytail-review`, `/ponytail-audit`, `/ponytail-debt`,
`/ponytail-gain`, `/ponytail-help`.
